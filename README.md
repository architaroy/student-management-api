# Student Management API

A backend API project for student management, built with Node.js, Express, and Mongoose.

## Technologies

- Node.js
- Express
- MongoDB with Mongoose
- dotenv

## Project Structure

- `config/` — configuration
- `controllers/` — request handling
- `middleware/` — middleware
- `models/` — data models
- `routes/` — API routes
- `server.js` — server entry point

## Getting Started

1. Install the project dependencies by running `npm install`.
2. Create a `.env` file and add the environment variables required by the project.
3. Start the development server by running `npm run dev`.

## About

This project organizes API routes, controllers, models, middleware, and configuration into separate folders.
